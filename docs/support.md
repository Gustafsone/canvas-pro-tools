# Support

Canvas Pro-Tools is maintained by one person, so the clearest reports get fixed fastest.

## Before you report a problem

- Check the feature is switched on in the popup, then reload the Canvas page.
- Look through [Troubleshooting]({{ '/troubleshooting/' | relative_url }}).
- Check the [Changelog]({{ '/changelog/' | relative_url }}) to see whether a newer version exists.

## Report a bug or ask for a feature

[Open an issue on GitHub](https://github.com/Gustafsone/canvas-pro-tools/issues/new/choose){: .btn .btn-primary }

An issue is a public note that anyone can read and add to, and it keeps a history of what was tried. You need a free GitHub account to open one.

Please include:

- The extension version, shown at the top of the popup.
- The browser and operating system.
- Which Canvas page you were on, for example a gradebook, SpeedGrader, or a rubric page.
- What you expected, and what happened instead.
- Any red error text from the page, if you can copy it.

{: .important }
> **Keep student information out of reports.** Issues are public. Do not paste student names, IDs, grades, or screenshots that show them. Describe the problem in general terms or blur the screenshot first.

## Privacy questions

Start with [Your data and privacy]({{ '/privacy/' | relative_url }}). For anything it does not answer, open an issue and label it as a privacy question, or write to GustafsonES@gmail.com.
