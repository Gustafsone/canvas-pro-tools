# Canvas Pro-Tools

A Chrome extension that adds practical tools to the Canvas LMS interface for instructors, deans, and administrators. Everything runs in your browser against the Canvas site you are already signed in to.

## What is in it

Features are grouped by who they help. Turn each one on or off from the toolbar popup.

- **[For everyone]({{ '/features/everyone/' | relative_url }}):** Gradebook Review Tracker, What-If Grades, Rubrics+, Assignment Details, and Checkpoint Rubric Mapper.
- **[In SpeedGrader]({{ '/features/speedgrader/' | relative_url }}):** Quiz Nav and Highlighting, Graded At Timestamp, and Avatar Zoom.
- **[For admins and deans]({{ '/features/admin/' | relative_url }}):** Admin Course Links and User Enrollments.

## Before you install

**Compatibility.** The extension runs on Canvas sites hosted at an `instructure.com` address, such as `myschool.instructure.com`. It does not run on Canvas sites served from a custom domain. It needs desktop Chrome or another Chromium browser that supports extensions.

## Your data

The extension does not collect, send, sell, or share any data. Settings and review markers stay in your browser on your own device. See [Your data and privacy]({{ '/privacy/' | relative_url }}) for the details.
