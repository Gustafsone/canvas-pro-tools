# Features

Canvas Pro-Tools has ten features. Each one can be switched on or off in the **Tools** tab of the toolbar popup, and each has a short Tips and Help section in the popup too.

| Feature | What it does | Default | Guide |
|---|---|---|---|
| Gradebook Review Tracker | Mark and track student submission review status in the gradebook and SpeedGrader. | Off | [For everyone]({{ '/features/everyone/' | relative_url }}) |
| What-If Grades | Try hypothetical scores on a student's grades page and see the effect on current and final grades. | On | [For everyone]({{ '/features/everyone/' | relative_url }}) |
| Rubrics+ | Rubric sorting, CSV export and import, details, and editing of locked rubrics. | On | [For everyone]({{ '/features/everyone/' | relative_url }}) |
| Assignment Details | Annotate the assignments list with submission type, grade impact, and rubric. | On | [For everyone]({{ '/features/everyone/' | relative_url }}) |
| Checkpoint Rubric Mapper | Map rubric criteria to discussion checkpoints so SpeedGrader fills in the checkpoint grades. | Off | [For everyone]({{ '/features/everyone/' | relative_url }}) |
| Quiz Nav and Highlighting | Color-code quiz navigation links by question status. | On | [In SpeedGrader]({{ '/features/speedgrader/' | relative_url }}) |
| Graded At Timestamp | Show when a submission was graded and whether it was manual or automatic. | On | [In SpeedGrader]({{ '/features/speedgrader/' | relative_url }}) |
| Avatar Zoom | Hover a student's avatar in SpeedGrader to zoom it. | Off | [In SpeedGrader]({{ '/features/speedgrader/' | relative_url }}) |
| Admin Course Links | Quick-access links under each course in the admin course search results. | Off | [Admin and dean tools]({{ '/features/admin/' | relative_url }}) |
| User Enrollments | Search, filter, and sort the Courses list on a user's page. | Off | [Admin and dean tools]({{ '/features/admin/' | relative_url }}) |

## Why some features start off

The Gradebook Review Tracker and Checkpoint Rubric Mapper need setup before they do anything useful. Avatar Zoom is a matter of preference. Admin Course Links and User Enrollments serve a narrower audience. Features that work on sight start on.

## Where features work

Features only act on the Canvas pages they are built for, and only on `instructure.com` Canvas sites. If a feature does not appear, see [Troubleshooting]({{ '/troubleshooting/' | relative_url }}).
