Tools i
Everyone Available to all instructors
📊 Gradebook Review Tracker
Mark and track student submission review status in the gradebook and SpeedGrader.
🔢 What-If Grades
Adds a What-If Score column to the instructor view of a student's grades page. Type hypothetical scores to see the impact on current and final grades in real time.
📋 Rubrics+
Enhances Canvas rubrics: sorts the Find a Rubric dialog by current course, adds CSV export to rubric pages, assignments, discussions, and quizzes, and adds per-rubric export icons and Import Rubric, Download Template, and Export All Rubrics buttons to the course rubrics list page. Flags whether an assignment's rubric is actually used for grading, adds a Load Rubric Details button to the rubrics list showing each rubric's context, assignment associations, and outcome criteria, and shows an associations report on an individual rubric page listing everything that rubric is attached to. On a rubric attached to several assignments, an Unlock rubric for editing button lets you edit it, and Restore associations re-attaches the assignments afterward.
📝 Assignment Details
Adds a "Load assignment details" item to the options menu on the assignments index page. Annotates each assignment with its submission type, whether it affects the final grade, and its rubric (linked, showing grading use and outcome criteria). External tool assignments show the tool's name, and Classic and New Quizzes are labeled.
🗺️ Outcome Map
Adds an Outcome Map button to the course Outcomes page. It opens a new tab with every assignment, and every Classic Quiz question bank aligned to an outcome, as a row and every outcome as a column, marking each alignment and counting coverage. Each outcome is tagged Institution, This course, or Other course, and notes show whether outcome criteria count toward the grade and whether the course is a Blueprint. A Cleanup tab gives a suggested fix order, marks suggested removals as Likely remove, shows whether Canvas will let you remove each outcome yet, and lists possible duplicates, outcomes nothing uses, outcomes that may belong to another course, rubrics not attached to any assignment, and assignments with no outcome. Refresh, export to CSV, or print. Read-only: it never changes Canvas.
🗂️ Checkpoint Rubric Mapper
For checkpoint-enabled discussions: assign each rubric criterion to a checkpoint. Mapping pills appear on discussion rubrics and on individual rubric pages, and the course rubrics list marks which rubrics are already mapped. In SpeedGrader, saving the rubric assessment sums the mapped scores into the Reply to Topic and Required Replies grade boxes.

💡 Tips & Help
🛠 Tools tab
Toggle individual features on or off. Most changes take effect on the next page load.
📊 Tracker tab
Lists all courses you have enabled for review tracking. Use the Global toggle to pause tracking across all courses at once without losing any data. Switch to the 🎨 States sub-tab to customize your review workflow — add up to 4 custom states with your own emoji, label, and indicator color.
🔗 Links tab
Controls which quick-access links appear beneath each course in the Admin course search results. Toggle links on or off, and use the ↑ and ↓ buttons to change their order.
💾 Data tab
Manage your Canvas Pro-Tools data by category. Tracker, Links, and Mappings can each be exported or cleared on their own, and Settings can be exported. Importing is done through Full Backup: the file is inspected first, then you choose which categories to restore. Clear All removes tracker data, links, mappings, and any saved rubric association snapshots for this Canvas instance, but never your feature settings. Rubric association snapshots saved by Rubrics+ are not included in exports or backups, and are kept until you restore that rubric or use Clear All.
📊 Gradebook Review Tracker
Enable tracking on any course by opening its gradebook and toggling the tracker from the ▾ menu. Click the status indicator on the left side of any grade cell to set a review status, or click the ≡ button in a column header to mark all visible students at once. Status markers also appear in the submission tray and SpeedGrader, and sync back to the gradebook automatically.
⚡ SpeedGrader
A Review Status badge appears in the grade area. Click it to mark the current student. The badge updates as you navigate between students and syncs back to the gradebook.
🧭 Quiz Nav & Highlighting
Color-codes quiz navigation links by question status: pale yellow = unanswered, light pink = incorrect, light purple = needs manual review (essay, short answer, or fill-in-multiple-blanks). Works in both SpeedGrader and the standalone quiz history view.
📋 Rubrics+
When you open the Find a Rubric dialog, the current course floats to the top of the list and term information is added to each entry. An Export CSV button appears on individual rubric pages, assignments, discussions, and quizzes — click it to download the rubric as a spreadsheet-ready CSV file. On quiz pages the CSV opens in a new tab instead of downloading directly, so allow pop-ups for your Canvas site if nothing appears. On the course Rubrics list page, each rubric row has a persistent download icon (between the edit and delete icons) to export that rubric directly. The sidebar also adds four buttons: Import Rubric to upload a CSV and create a new rubric in the course; Download Template to get a blank CSV pre-formatted for import; Export All Rubrics to download every rubric in the course as a single CSV file; and Load Rubric Details to show each rubric's context, assignment associations, and outcome criteria. When importing a multi-rubric CSV, Canvas creates each rubric separately using the Rubric Name column to distinguish them. On an assignment, a badge flags whether the attached rubric is actually used for grading, and an individual rubric page gains an associations report listing everything that rubric is attached to. Canvas hides Edit on a rubric attached to more than one assignment. On that rubric's page, click Unlock rubric for editing: your Assignment associations are saved in your browser, all but the first are removed, and the page refreshes so Edit appears. After you edit and save the rubric, click Restore associations to re-attach them. Restore can be retried if it is interrupted, and afterward the page compares each assignment's points with what they were before. Only assignment associations are changed.
📝 Assignment Details
On the course Assignments page, open the ⋮ options menu at the top and choose "Load assignment details". Each assignment is then annotated in place with its submission type, whether it counts toward the final grade, its attached rubric (linked, with whether that rubric is used for grading and any outcome criteria). External tool assignments show the tool's name, and Classic and New Quizzes are labeled. Nothing is changed on the page until you run it.
🗺️ Outcome Map
On a course's Outcomes page, click Outcome Map next to Find. A new tab opens with assignments down the side, grouped by assignment group, and outcomes across the top, grouped by outcome group. The map appears in a few seconds. It then reads the course's Classic Quiz question banks (a status line counts them off) and adds a Question banks row for each bank aligned to an outcome, with the bank's mastery % in the tooltip. A key above the map explains the marks: ● means a rubric criterion or question bank is aligned to the outcome. In a course that mixes graded and tracked-only outcome criteria, ○ marks the tracked-only ones, which record outcome results but do not count toward the grade. Under each column number, Inst. marks an Institution outcome, Course one created in this course, and Other one created in a different course. Hover a column or mark for the full outcome, rubric, criterion, or bank. Notes above the map say what it covers (rubrics and Classic Quiz banks in this course, not New Quizzes item banks or banks stored elsewhere), whether outcome criteria count toward the grade, and, in a Blueprint course, where shared content should be fixed. The legend under the map lists each outcome's title, source, description, how many assignments and banks use it, and whether Canvas will let you remove it now. Outcomes that share a number within one group are labeled 1a, 1b, and so on. A ⚑ marks an outcome the map suggests you likely remove: a course-level duplicate that nothing uses (when its set has an Institution or in-use outcome to keep), or an outcome whose description names a different course code, such as NRSG 403 in an NRSG 412 course. These are suggestions, so check before removing. The Cleanup tab waits until the question banks are read, so an outcome assessed only through a quiz bank is never shown as unused. It starts with a suggested fix order and the Likely remove list, then lists possible duplicate outcomes (a wording match, so review before acting), outcomes no assignment or bank uses, outcomes that may belong to another course, rubrics not attached to any assignment that still carry outcomes, assignments with no outcome, duplicate rubric copies, outcomes in use but missing from the course, and whether more than one outcome group is in use. Each item links to its Canvas page, where any fix is made. Click Refresh afterward to check again. Export Map CSV and Export Cleanup CSV download spreadsheets, and Print gives a landscape copy of both tabs. The map only reads from Canvas. It changes nothing and saves nothing. Works on the classic Outcomes page.
🕐 Graded At Timestamp
Displays when a submission was graded and whether it was graded manually or auto-graded. Appears in the submission info area of SpeedGrader.
🔍 Avatar Zoom
Hover over a student's avatar in SpeedGrader to zoom it to 2×. Helps identify students by photo when grading.
🗂️ Checkpoint Rubric Mapper
On checkpoint-enabled discussions with a rubric attached, each criterion row shows a small pill. Click the pill to assign that criterion to "Reply to Topic", "Required Replies", or "Ignore". The same pills appear on an individual rubric's page, so a rubric can be mapped before it is ever attached to a discussion, and the course Rubrics list marks each already-mapped rubric with a "✓ Checkpoint mapped" badge. Mappings are saved per rubric and reused everywhere that rubric is used. In SpeedGrader, saving the rubric assessment sums the mapped scores and writes them to the checkpoint grade boxes.
🔢 What-If Grades
Open any student's grades page as an instructor and click "📊 What-If Grades" to reveal a new column. Type a hypothetical score for any assignment — including 0-point extra credit assignments — to instantly see how it affects the student's current and final grade. Type EX to model the assignment being excused and dropped from the calculation. Group subtotals update live too. Click ↺ Reset to clear all hypothetical scores.
🔗 Admin Course Links
Adds quick-access links beneath each course in the Admin course search results page. Configure which links appear and their order in the 🔗 Links tab.
🎓 User Enrollments
On a user's page in Canvas, the Courses list gains a search box plus term and course-status filters, and is re-sorted so active enrollments come first. Within that, courses are grouped by Default Term, then named terms such as Master Templates, then dated terms (for example FA-26) with the newest first. A count above the list shows how many enrollments are currently visible. Useful on accounts with long enrollment histories.
