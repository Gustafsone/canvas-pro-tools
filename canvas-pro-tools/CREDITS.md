## Adapted Features — Canvas LMS Mods (Code with Ski)

Original work by Code with Ski ([@Code-with-Ski](https://github.com/Code-with-Ski))
published under the [Canvas-LMS-Mods](https://github.com/Code-with-Ski/Canvas-LMS-Mods)
project.

These features were reimplemented against Canvas Pro-Tools' own conventions
rather than copied. The behaviour, the Canvas endpoints, and the presentation
approach are adapted from the original; the code is not.

| Feature | File | Original Source |
|---|---|---|
| Rubric Used-for-Grading Badge | `rubric-info.js` | [feature-rubric-use-for-grading-notification](https://github.com/Code-with-Ski/Canvas-LMS-Mods/tree/main/canvas-mods/courses/assignments/feature-rubric-use-for-grading-notification) |
| Load Rubric Details | `rubric-info.js` | [feature-load-rubric-details](https://github.com/Code-with-Ski/Canvas-LMS-Mods/tree/main/canvas-mods/shared-locations/rubrics/feature-load-rubric-details) |
| Rubric Associations Report | `rubric-info.js` | [feature-load-rubric-associations](https://github.com/Code-with-Ski/Canvas-LMS-Mods/tree/main/canvas-mods/shared-locations/rubrics/feature-load-rubric-associations) |
| Load Assignment Details | `assignment-details.js` | [feature-load-assignment-details](https://github.com/Code-with-Ski/Canvas-LMS-Mods/tree/main/canvas-mods/courses/assignments/feature-load-assignment-details) |
| User Enrollments | `user-enrollments.js` | [feature-enhance-courses-list](https://github.com/Code-with-Ski/Canvas-LMS-Mods/tree/main/canvas-mods/shared-locations/users/feature-enhance-courses-list) |

User Enrollments implements a subset of the original: course-name search, term
filter, and course-status filter. The original also shipped course-code search,
SIS-ID search, enrollment-status and role dropdowns, and a resizable pane. Its
sort order is specific to Canvas Pro-Tools and is not from the original.
